# 本机浏览器控制：后续任务计划

版本：LOCAL-1 · 2026-09-04。用户已确认仅本机访问，并要求按 GitHub 调研结论安排后续工作。本文是主规划 M0–M8 的本机增量，下一任务以 PROJECT_STATUS 的最新状态为准。换电脑继续开发不恢复异机远控产品需求。

## 已确定的方向

保留 React/TypeScript、.NET 10 Host/DesktopAgent、WGC、H.264 硬编 + WebSocket/WebCodecs、JPEG 兼容。优先解决现有本机输入和媒体延迟，再用 Sunshine + moonlight-web-stream 进行有边界的对照，凭实测决定是否有必要变更架构。noVNC/Sunshine 用于事件合并与调度参考，RustDesk/Selkies 为次要参考。

现有媒体与输入入口仍是 M1 实验，不是正式 React 控制台，也没有完成发布包。当前实现需 NX 可见、浏览器与 NX 分处两个物理屏幕；这是待解决/验收的实现限制，不是已确认的永久产品限制。网页中 NX/TIA 左右等宽双栏与物理双显示器是不同要求。
