# M1 原生输入阶段证据与续接边界

记录日期：2026-09-04。当前仅为 L1 自身窗口验证，M1-02 未完成，也不是浏览器远控或 NX/TIA 验收。

## 已保存的实现

- NativeInputEvents 定义 x64 SendInput ABI、扫描码、左右修饰键、鼠标三键、双轴滚轮、虚拟桌面绝对坐标及 Unicode 成对事件。
- NativeInputBackend 在发送前重新校验目标，检查实际提交数量；Unicode 分批不切断代理项，部分提交保留待释放状态，不重放文本。
- WindowsInputEnvironment 检查交互桌面、会话、进程身份、完整性级别、DPI、场景几何、前台/焦点/命中窗口。窗口生命周期证明由调用方提供；自测只证明自身窗口生命周期，尚未接入生产捕获注册表。
- InputSession 保留持键账本及瞬时 Unicode 释放路径。内部心跳失效阈值为 5500 毫秒，给轮询与原生释放预留时间；外部 6 秒目标不变。完整 Host/Agent 故障保护仍待实现。
